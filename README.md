## Como publicar

Extraia o ZIP e envie os arquivos `index.html`, `configuracao.js`, `script.js`, `style.css` e pasta `assets` para a raiz do repositório GitHub. O site estático também pode ser publicado pelo Vercel e GitHub Pages, sem comando de build. Para mudar os contatos ou banners no futuro, edite os campos iniciais de `configuracao.js`.

**Resoluções sugeridas:** 1080 × 1440 px para banners rotativos, 1920 × 800 px para Pronta Entrega, 1080 × 608 px para banners das ligas e 1080 × 1080 px para escudos/bolinhas.
